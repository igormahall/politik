# Politik v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Robô diário, sem servidor, que coleta publicações oficiais (federal, Amazonas, Manaus) e imprensa, filtra por código, traduz e agrupa em temas com o Claude Code (assinatura Pro), publica um site estático e manda um resumo no Telegram.

**Architecture:** Pipeline Python em etapas independentes (coletar → filtrar → [Claude Code] → validar → site → enviar), cada uma lendo/escrevendo JSON em `data/`. O Claude Code roda via `anthropics/claude-code-action@v1` executando uma skill do repositório que só lê/escreve arquivos em `data/`. GitHub Actions (cron) orquestra; dados são commitados; o site vai para o GitHub Pages.

**Tech Stack:** Python 3.12, httpx, feedparser, Jinja2, pytest; GitHub Actions; `anthropics/claude-code-action@v1`; Telegram Bot API; GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-29-politik-design.md`

## Global Constraints

- Custo extra zero: nada de API paga, servidor ou VPS. Claude só via `claude_code_oauth_token: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}` no `claude-code-action`; nunca usar o token fora do Claude Code.
- Todo texto voltado ao usuário em **português do Brasil**.
- Neutralidade (spec §4.2): sem adjetivo valorativo, opinião ou especulação; nunca dizer se é bom/ruim; fato de fonte única sinalizado "segundo apenas <veículo>"; todo item com link; partido do autor como "Dep. Fulano (PARTIDO–UF)".
- Senado: usar `https://legis.senado.leg.br/dadosabertos/processo`, nunca `/materia/pesquisa/lista` (descontinuado).
- Teto: no máximo **25** itens em destaque por dia para o Claude; pendentes expiram após **2** dias e vão para os menores.
- Prioridade: (1) itens ligados a tema ativo, (2) normas, (3) votações e tramitação, (4) proposições federal > estadual > municipal.
- Tema fica inativo após **30** dias sem novidade.
- Cron `0 10 * * *` (10:00 UTC = 6h Manaus). Dia de referência = ontem em `America/Sao_Paulo`.
- Mensagem do Telegram ≤ **4096** caracteres por envio; dividir se passar.
- Repositório público: nenhum segredo nos arquivos. Segredos: `CLAUDE_CODE_OAUTH_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `INLABS_EMAIL`, `INLABS_SENHA`.
- Nunca contornar paywall.
- Nada descartado em silêncio: todo item coletado termina em destaque, pendente ou menores.

## Review Focus

1. **Uma fonte fora do ar ou devolvendo erro/JSON inesperado** → as outras seguem, o resumo sai com "⚠️ {nome da fonte} indisponível hoje.". Teste: Task 9 `test_coletar_fonte_falha_continua`.
2. **Etapa do Claude falhou ou não escreveu nada** (cota esgotada) → o resumo sai com ementas originais e o aviso "Tradução indisponível hoje". Os itens voltam para pendentes. Testes: Task 10 `test_validar_sem_diario_reenfileira` e Task 13 `test_compor_sem_traducao`.
3. **Dia sem nenhuma novidade** (fim de semana, recesso) → a mensagem sai mesmo assim: "Nenhuma novidade oficial ontem." Teste: Task 13 `test_compor_dia_vazio`.
4. **Ementa/título com `<`, `&` ou `>`** → escapado no HTML do Telegram e do site, sem quebrar o envio. Testes: Task 13 `test_compor_escapa_html` e Task 12 `test_site_escapa`.
5. **Pipeline rodado duas vezes no mesmo dia** (rerun manual) → nada duplicado em `data/`. Teste: Task 1 `test_salvar_itens_idempotente`.

**Formatos de dados (fixados aqui, usados por todas as tasks):**

- `data/brutos/<D>/<fonte>.json`: `list[Item]`.
- `data/selecionados/<D>.json`: `{"data": D, "destaques": [Item], "noticias": [Item], "menores": [Item], "fontes_indisponiveis": [str]}`.
- `data/pendentes.json`: `[{"item": Item, "primeira_vez": D}]`.
- `data/fichas/<item_id_seguro>.json`: **Ficha** = `{"item_id", "nivel", "tipo_simples", "situacao", "titulo", "o_que_e", "quem_propos", "o_que_muda", "proximo_passo", "fontes": [{"nome","url"}], "fonte_unica": bool, "temas": [slug], "data": D}`.
- `data/temas/<slug>.json`: **Tema** = `{"slug", "nome", "inicio", "ativo": bool, "ultima_novidade": D, "palavras_chave": [str], "resumo_ate_aqui", "explica_do_zero", "linha_do_tempo": [{"data","fato","fontes":[{"nome","url"}],"fonte_unica": bool}]}`.
- `data/diario/<D>.json`: `{"data": D, "temas": [{"slug", "novo_hoje", "aviso_fonte_unica": str|null}], "fichas": [item_id]}`.
- `item_id_seguro` = `item_id` com `:` e `/` trocados por `_`.
